# ADR-0004: Дизайн-система

- Статус: принято
- Дата: 2026-09-27
- Подробный гайд: [docs/design-system.md](../design-system.md)

## Контекст
Референсы (`designs/`): лендинг Mynt (светлый «воздушный» интерфейс, зелёный акцент, крупные плотные заголовки,
метки «• раздел»), формы с подписями над полями, виджеты-карточки с большими скруглениями, стеклянные
всплывашки, узкий сайдбар из иконок. Механики продукта — по мотивам bragbook.io (записи, коллекции/теги,
фильтры по периодам, статистика, композитор выжимок).

## Решение
1. **Светлая и тёмная темы.** Цвета и тени — токены; тёмная тема — переопределение токенов для
   `html[data-theme='dark']`, компоненты о теме не знают. Пользователь переключает светлую/тёмную
   кнопкой в шапке; пока выбора не было — берётся системная тема. Выбор хранится
   в localStorage. Тема ставится скриптом `public/theme-init.js` до первой
   отрисовки — без вспышки светлой темы.
2. **Токены** — CSS-переменные в `apps/web/src/styles/tokens.css`: цвета (поверхности, текст, бренд, статусы),
   типографика, отступы (шаг 4px), скругления, тени, размеры контролов, движение, слои, сетка.
   В компонентах — только токены, никаких «сырых» значений цвета и размеров.
3. **Шрифты** — Manrope (интерфейс) и JetBrains Mono (коды, ключи, «терминальные» акценты), оба с кириллицей,
   раздаются с нашего домена (`@fontsource-variable/*`) — никаких внешних CDN (CSP `font-src 'self'`).
4. **Иконки** — `lucide-vue-next` (ISC), размер 16/18/20, толщина по умолчанию.
5. **Примитивы** — `apps/web/src/ui/Ui*` (Button, IconButton, Input, OtpInput, Checkbox, Card, Eyebrow, Alert,
   Progress, Spinner, Logo). Фичи собираются из примитивов; новый примитив появляется, когда паттерн
   повторяется второй раз. Витрина — `/dev/ui` (только в dev).
6. **Формы** — единые правила валидации и отображения ошибок (гайд, раздел «Формы»), composable `useZodForm`
   на схемах из `packages/shared`.
7. **Маскот** — ретро-монитор с глазами (оригинальный персонаж): зелёные пиксельные глаза на тёмном экране,
   вместо рта — мигающий курсор `_` (продолжение терминальной заглушки). Живёт на экранах входа/регистрации и в
   пустых состояниях. Вся мимика — на экране: следит глазами за вводом логина, зажмуривается `> <` на пароле и
   кодах 2FA, подмигивает одним глазом при показе пароля, в ожидании моргает/наклоняется/подпрыгивает/«глючит»,
   через 45 секунд засыпает (экран тускнеет). Рассматривались сова и красная панда.
8. **Доступность** — контраст текста ≥ 4.5:1, видимый фокус, `aria-*` у интерактивных элементов,
   уважение `prefers-reduced-motion` (анимации отключаются, состояния остаются).

## Последствия
- (+) Единый визуальный язык, быстрое ревью: стили компонента — в его `.css`, значения — из токенов.
- (+) Никаких внешних ресурсов — строгая CSP и честная страница «Принципы».
- (−) Свой набор примитивов нужно поддерживать (осознанно: UI-кит сторонней библиотеки тянет свой стиль и вес).
