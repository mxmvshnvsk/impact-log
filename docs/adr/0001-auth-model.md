# ADR-0001: Модель аутентификации

- Статус: принято
- Дата: 2026-09-27

## Контекст
Сервис для разработчиков, хранит рабочие заметки. Цели: максимум безопасности, минимум персональных данных
(в т.ч. чтобы по возможности не обрабатывать ПДн в смысле 152-ФЗ), минимум «заморочек» для пользователя.

## Решение
1. **Без почты и телефона.** Идентификатор — логин (никнейм). Писем сервис не отправляет.
2. **Пароль**: минимум 12 символов, хеш Argon2id. Опционально — проверка по HIBP (k-anonymity).
3. **2FA (TOTP) обязательна.** Подключается на этапе регистрации: QR-код → подтверждение первым кодом.
   Без подтверждённой 2FA аккаунт не активируется.
   - TOTP-секрет хранится зашифрованным (ключ — в env сервера, не в БД).
   - Защита от повторного использования кода в пределах окна.
4. **Резервные коды**: 10 одноразовых кодов, показываются один раз при регистрации (скачать/скопировать,
   подтверждение «я сохранил»). В БД — только хеши. Можно перевыпустить (старые аннулируются).
5. **Восстановление доступа — только резервными кодами.** Потеря пароля/устройства и кодов = потеря аккаунта.
   Это явно сообщается при регистрации.
6. **Сессии**: cookie httpOnly + Secure + SameSite; список активных сессий, «завершить все остальные»;
   смена пароля или 2FA завершает все сессии.
7. **Защита от перебора**: rate limiting на логин и ввод 2FA (по логину и IP); одинаковые ответы
   для «нет пользователя» и «неверный пароль».
8. **Удаление аккаунта** — полное, с подтверждением паролем и 2FA. **Экспорт** всех данных (JSON/Markdown).
9. **Логи и трекинг**: IP в логах усечены, ротация 7–14 дней; без внешней аналитики; только сессионная cookie.

## Последствия
- (+) Почти нет ПДн; нет зависимости от почтового провайдера и SPF/DKIM.
- (+) Единый высокий уровень безопасности для всех аккаунтов.
- (−) Нет «забыл пароль» по почте — пользователь, потерявший коды, теряет аккаунт.
- (−) Чуть больше трения при регистрации и входе.

## На будущее
- Passkeys (WebAuthn) как второй фактор / беспарольный вход.
- Страница «Как мы храним данные» к публичному запуску; консультация юриста по 152-ФЗ.
