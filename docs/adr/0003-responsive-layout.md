# ADR-0003: Адаптивность и сетка

- Статус: принято
- Дата: 2026-09-27

## Решение

Интерфейс адаптивный, **mobile-first**: базовые стили пишутся для mobile, шире — через `@media`.

| Режим   | Ширина окна    | Дизайн-макет | Боковые отступы (`--gutter`) |
|---------|----------------|--------------|------------------------------|
| mobile  | до 719px       | 375px (не ломаться до 320px) | 16px |
| tablet  | 720–1199px     | 720px        | 24px |
| desktop | от 1200px      | 1200px       | 32px |

Между опорными ширинами вёрстка тянется, отдельных макетов нет.

### Ширины
- **Каркас** (`--layout-max-width: 1200px`, класс `.l-container`): шапка, сайдбар + контент, дашборды.
  По центру, на wide screen не растягивается.
- **Колонка текста** (`--content-max-width: 720px`, класс `.l-content`): записи, превью Markdown, выжимки —
  ~65–75 символов в строке, комфортная длина для чтения.

### Реализация
- Именованные медиазапросы в `apps/web/src/styles/media.css`: `--tablet`, `--desktop`, `--mobile-only`,
  `--tablet-only`. Доступны в любом CSS-файле без импорта (PostCSS: `postcss-custom-media` +
  `@csstools/postcss-global-data`). Пишем `@media (--tablet) { … }`, числа в компонентах не используем.
- Токены сетки — CSS-переменные в `styles/base.css`, layout-классы — `styles/layout.css`.
- JS: `useBreakpoint()` (`composables/useBreakpoint.ts`) на `matchMedia` — **только** когда на разных экранах
  рендерятся разные компоненты. Всё остальное — CSS.
- Значения брейкпоинтов продублированы в `constants/breakpoints.ts` (для JS) и `styles/media.css` (для CSS) —
  менять синхронно.
