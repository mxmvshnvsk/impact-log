# Security

impact log encrypts entries end to end, so we take vulnerability reports seriously.

**Please don't open a public issue for a vulnerability.** Report it privately on GitHub:
[Security → Report a vulnerability](https://github.com/mxmvshnvsk/impact-log/security/advisories/new).
Include what is affected, how to reproduce it and the impact you see. We'll reply in the advisory.

In scope: the web app and API at impact-log.com, the Chrome and VS Code extensions and the `impact-log` CLI.
The threat model and the known limits of end-to-end encryption in a web app are described on
[impact-log.com/principles](https://impact-log.com/principles) and in [docs/adr](docs/adr).
